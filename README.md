# Java Learning Programs - Semester 5

> **College Laboratory Programs** | A collection of Java programs completed during the 5th Semester laboratory cycle while pursuing Bachelor of Science in Computer Science at Farook College, focusing on core Java concepts and Object-Oriented Programming principles.

This repository contains a comprehensive collection of structured Java programs that progress from fundamental programming concepts through advanced Object-Oriented Design patterns. Each program was developed as part of the Semester 5 Java Lab curriculum and is designed as a standalone learning module while building a cohesive understanding of Java fundamentals and object-oriented concepts.

## 📚 Program Catalog

### Procedural Programming & Control Flow

Fundamental programs exploring basic Java syntax, conditional logic, and iterative control structures.

- **01_OddEven.java** — Conditional logic implementation for number classification
- **02_LargestOfThree.java** — Comparative operators and control flow decisions
- **03_PrimeNumbers.java** — Algorithmic implementation of prime number detection
- **04_Fibonacci.java** — Sequence generation using iterative patterns
- **05_Armstrong.java** — Mathematical validation and loop-based computation
- **06_MarksGrades.java** — Grade mapping and conditional evaluation systems

### Functional Programming & Recursion

Programs demonstrating algorithmic problem-solving through functions and recursive approaches.

- **07_FactorialRecursion.java** — Recursive function design and stack-based computation
- **11_TriangleAreaOverload.java** — Method overloading for geometric calculations
- **12_RectangleAreaCompare.java** — Comparative analysis and function polymorphism

### Data Structures & Algorithms

Programs working with arrays, matrices, and fundamental algorithmic patterns.

- **08_SortArray.java** — Array manipulation and sorting algorithm implementation
- **09_MatrixTranspose.java** — 2D array operations and matrix mathematics
- **10_AvgCmdLine.java** — Command-line argument processing and statistical computation

### Object-Oriented Programming Fundamentals

Introduction to objects, encapsulation, and object instantiation patterns.

- **13_ComplexNumberAdd.java** — Custom object design with operator-like functionality
- **14_InheritanceEmployee.java** — Class hierarchy design and inheritance patterns
- **15_StudentObjectArray.java** — Object array management and collection operations
- **16_OverrideGreatest.java** — Method overriding and polymorphic behavior

### Advanced Object-Oriented Concepts

Programs demonstrating advanced design patterns including interfaces and abstraction.

- **17_ShapeInterface.java** — Interface-based design and polymorphic implementations
- **18_ThreadHelloHai.java** — Concurrent programming and thread lifecycle management
- **19_ArithmeticException.java** — Exception handling and custom exception design
- **20_Packages.java** — Namespace organization and modular code structure
- **21_Client.java** & **21_Server.java** — Network programming and socket communication

### Supporting Resources

- **Algorithms.md** — Detailed algorithm documentation and complexity analysis
- **p1/Prime.java** — Packaged utility module demonstrating package organization

## 🚀 Quick Start

### Prerequisites

- Java Development Kit (JDK) 8 or higher installed
- Command-line terminal or IDE of your choice

### Compilation & Execution

**Single File Compilation:**

```bash
javac ProgramName.java
java ProgramName
```

**With Command-Line Arguments:**

```bash
javac ProgramName.java
java ProgramName arg1 arg2 arg3
```

**Client-Server Communication Example:**

```bash
# Terminal 1 - Start Server
javac 21_Server.java
java Server

# Terminal 2 - Run Client
javac 21_Client.java
java Client
```

1. **Phase 1: Fundamentals (01-06)** — Start with procedural programming basics
